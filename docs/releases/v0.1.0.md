First release of Isolated: run any Windows program in a sandbox from the right-click menu.

**Download `isolated.exe` below, open it, and choose Settings > Install for this user.** No administrator rights needed. Windows 10 (1809) or later, 64-bit.

### What's in it
- Right-click **Run in Isolated** on programs, shortcuts, `.bat`, `.cmd` and `.ps1` files, with offline, with-options, and edit-profile entries.
- AppContainer sandbox per app: no access to your files, no network and no clipboard unless granted; its own private user folders.
- Job Object per sandbox: everything the program starts stays inside; memory, CPU and process limits; clipboard and system-setting restrictions.
- Temporary folder grants with a crash-safe cleanup journal.
- A small window to manage app profiles, see and stop running sandboxes, and change settings.
- Built-in profiles: strict, offline, online, game-mod, dev-build, compatible.
- Command-line tool: `isolated run`, `ps`, `kill`, `profile`, `update`, and more.
- **Automatic updates:** Isolated checks for new releases when its window opens and can update itself in place after verifying the download's SHA-256.

### Known limits
- Releases are not code-signed yet, so SmartScreen may warn on first run.
- On Windows 11 the menu entry is under **Show more options**.
- Not yet available: host allowlists and loopback-only network, separate-desktop mode, window borders, denial notifications, and learn mode.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
