Windows of apps running in Isolated now show that they are isolated.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Changes
- **Isolated windows are marked.** The active window of an isolated app gets a colored frame, and its title starts with **[Isolated]**, or **[Isolated: container name]** for apps in a container or an isolated folder. The tag also shows on the taskbar and in Alt+Tab.
- A window with no frame and no tag is **not** isolated. That includes anything that asked for administrator rights and that you approved: Windows starts those outside the sandbox.
- The frame is hidden for full-screen windows (games, videos), so it never gets in the way.
- **Settings > Show which windows are isolated** turns the frame and the title tag on or off and picks the frame color. Changes apply to apps started afterwards.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
