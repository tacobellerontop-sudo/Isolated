Apps in "Works with more apps" containers can now be kept out of your files.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Changes
- **Hide your files from "Works with more apps" containers.** These containers are for apps that can't run locked down, such as Kryoto, Steam, and Electron or WebView2 apps. Before, their apps couldn't change your files but could read most of them. In **Settings**, turn on **Hide your files from "Works with more apps" containers** to have Isolated create a hidden Windows user and run these apps as it. Windows then keeps them out of your user folder (Documents, Desktop, Downloads, AppData) and your settings. They can still see programs installed for everyone, such as those in Program Files. Turning it on asks for administrator rights once. **Turn off** removes the hidden user again. From a terminal: `isolated sandbox-user setup` or `isolated sandbox-user remove`.
- Installers you run into such a container are copied into the container first, so the hidden user can run them.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
