Isolated can now install apps and keep them: run an installer inside a sandbox, then start the installed app from it any time.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### New: installed apps in boxes
- Right-click an installer (`.exe` or `.msi`) and choose **Install in Isolated...**, or use **Install an app...** in the new **Installed apps** tab.
- The installer runs inside a *box*, a sandbox that keeps its files. It starts without administrator rights and installs for the current user only, into the box. Inno Setup, NSIS, per-user MSI and Squirrel (Electron) installers are supported.
- When the installer finishes, Isolated saves the programs it created (from their Start menu shortcuts). They appear under **Installed apps** with a **Run** button and keep running in the box with its profile, so they still cannot see your files.
- Choose whether the installer may use the internet; the installed apps use the box's profile.
- Install more apps into the same box, add a program from the box by hand, open the box's folder, or delete a box and everything in it.
- Command line: `isolated box install`, `box run`, `box list`, `box add`, `box forget`, `box delete`.

### Fixes
- Programs in a fully isolated sandbox now get a working `%LOCALAPPDATA%` folder. Before, Windows pointed it at a folder that did not exist, which broke apps that store settings there.

### Known limits
- Installers that must change Windows itself (drivers, services, system-wide runtimes such as some Visual C++ redistributables) cannot run in a sandbox.
- Installers that refuse to run without administrator rights and offer no per-user mode will stop with their own error message.
- Releases are not code-signed yet, so SmartScreen may warn on first run.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
