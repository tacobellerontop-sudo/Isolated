Add your existing saves and settings to an isolated folder's sandbox.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### New
- **Private files** for each isolated folder in the **Folders** tab. Programs in an isolated folder keep their settings and saves in the sandbox, not in your user folder. This view shows those files. You can drop in existing saves, add files or folders from your PC, and copy anything out.
- It opens in **App data**, the folder that programs see as AppData\Local and AppData\LocalLow. A game that saves to `AppData\LocalLow\<company>\<game>` on your PC uses `App data\<company>\<game>` here. To bring an old save along, copy that `<company>` folder into App data while the game is closed. **Roaming** is the programs' AppData\Roaming.
- `isolated folder files <folder>` prints these paths.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
