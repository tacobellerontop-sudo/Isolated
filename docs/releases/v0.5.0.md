Isolated can now isolate a whole folder: programs started from it can use the other files in that folder, and nothing else of yours.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### New: isolated folders
- Right-click a folder, or the empty space inside an open folder, and choose **Isolate this folder...** (on Windows 11 it is under **Show more options**). Choose whether its programs may use the internet (off by default) and click **Isolate this folder**.
- Every program started from that folder or its subfolders can now read, change, add and delete the files in it. Your other files and everything outside the folder stay hidden from them. Copy and paste work.
- Start them with right-click **Run in Isolated** (the folder's settings are picked automatically) or with **Run** in the window's new **Folders** tab, which lists the programs in each folder.
- Programs in the same folder share one sandbox, so they keep the same settings and can start each other.
- The **Folders** tab also has an **Internet** switch, **Open folder**, **Edit** for all settings, and **Stop isolating** (the folder's files are never touched).
- Command line: `isolated folder add <folder> [--net]`, `isolated folder list`, `isolated folder remove <folder>`.

### Known limits
- Opening a program by double-clicking it still runs it outside the sandbox. Use **Run in Isolated** or the **Folders** tab.
- A whole drive, your whole user folder, and Windows or Program Files cannot be isolated.
- Very large folders take a moment to start, because Windows applies the access to every file in them on each start.
- Releases are not code-signed yet, so SmartScreen may warn on first run.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
