Fixes the missing administrator prompt when turning on **Hide your files from "Works with more apps" containers**.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Changes
- **Turn on** and **Turn off** for the hidden user now ask Windows for administrator rights from the Isolated window itself, so the prompt shows up in front. Before, Windows could hide it as a flashing icon in the taskbar.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
