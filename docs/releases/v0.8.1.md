Apps in a container can no longer quietly get things started outside it through an administrator prompt.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Changes
- **Fewer administrator prompts.** Programs in a container that ask for administrator rights now start without them instead of showing a Windows administrator prompt. Before, only installers were treated this way. Whatever users approve in such a prompt is started by Windows outside the container, with full rights, and no sandbox without a driver can keep it in.
- **A warning when a program leaves a container.** If an app in a container still gets another program started outside it (for example after an approved administrator prompt), Isolated shows a warning naming both, so users know that program is not isolated.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
