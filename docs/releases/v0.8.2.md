Kryoto game downloads now work in a container without any setup.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Changes
- **Kryoto's game folder is kept automatically.** A container with Kryoto in it keeps `C:\Users\<you>\Kryoto Games` inside the container by itself, so its downloads no longer fail with "Access is denied".
- **Leftovers move into the container.** If a kept folder already exists on your PC (for example from a download that failed before), what's in it moves into the container instead of the folder being skipped.
- **Problems are shown.** If a kept folder can't be set up, Isolated now says why in a message, even when the app was started from the Start menu or a shortcut.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
