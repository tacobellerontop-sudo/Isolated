Isolated can now install `.msi` apps into a box, and let an app see only the folders you pick.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### New: `.msi` installers work
- Right-click an `.msi` file and choose **Install in Isolated...**, or drop it on the Isolated window.
- Isolated unpacks the package into the box itself instead of handing it to Windows Installer (a system service that works outside any sandbox, which is why `.msi` installs used to fail). The programs from its Start menu shortcuts are saved under **Installed apps**.
- No code from the package runs. Anything beyond its files (registry settings, services, file types, files meant for Windows system folders) is left out, which most apps don't need.

### New: choose which folders an app can see
- Right-click a program and choose **Run in Isolated with folders...**. A small window lets you add folders (or drop them on it) and tick **Can change files** for the ones the app may save into. Everything else stays hidden, and access ends when the app exits.
- Your choice is offered again the next time you run that app.
- New built-in profile `folders` asks every time the app starts (no network; copy and paste work). Any profile can ask too: tick **Ask which folders to share each time the app starts**.
- Command line: `isolated run --ask-folders -- app.exe`; `--no-ask` skips the window.

### Changes
- The right-click menu is refreshed automatically after an update, so the new entry appears without reinstalling.

### Known limits
- `.msi` packages that keep their files outside the `.msi` (next to it, or in separate `.cab` files) cannot be unpacked yet.
- Apps that depend on what their installer sets up besides files (a service, a driver, registry settings) may not work when installed from an `.msi`.
- Releases are not code-signed yet, so SmartScreen may warn on first run.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
