Kryoto Desktop and other Tauri apps install, and choosing how locked down a container is got easier.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Changes
- **Protection, in plain words.** Installing an app or creating a container now offers **Locked down (recommended)**, where apps can't see your files, or **Works with more apps**, for apps built on web technology (Electron AI apps, Steam, Kryoto and other WebView2 apps, browsers). Other profiles are still under **Other profile**.
- **Tauri apps such as Kryoto Desktop.** Their installers quit at once in a locked-down container. Isolated now picks **Works with more apps** for installers named like Tauri and Electron ones. If an install into a locked-down container finds nothing, or the app turns out to be built on web technology, it offers to install it that way instead.
- A container that has no apps yet (for example after a failed install) can still change its protection.
- Isolated recognises WebView2 apps, and silent switches such as `/S` no longer stop it from installing NSIS setups for the current user, into the container.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
