Fixes games in an isolated folder getting stuck on their loading screen when they save files with long names.

**Already have Isolated?** It updates itself: open the window and choose **Update now**, or run `isolated update`. New users: download `isolated.exe` below, open it, and choose **Settings > Install for this user**.

### Fixed
- Programs in an isolated folder keep their AppData in the sandbox, at a path that was about 90 characters longer than the real one. Games that save files with long names, such as Workshop content, went past Windows' 260-character path limit and got stuck loading. The sandbox's part of the path is now about 45 characters shorter.
- Because of this, an isolated folder starts with fresh app settings once after updating. Settings saved by 0.5.0 or 0.5.1 are not carried over.

Verify the download: the SHA-256 is in `isolated.exe.sha256`.
